# Avatars Hitroom : prompts pour Google Flow

Format carré 1:1, fond noir uni (rendu transparent à l'intégration, comme les cadres). Un prompt complet par avatar, prêt à coller.

Style commun (déjà inclus dans chaque prompt) :

> Stylized 3D game avatar icon in the style of a premium mobile game collectible: chunky simplified shapes, smooth glossy hand-painted materials, slightly exaggerated proportions, bold clean silhouette that stays readable even when very small. Soft rim lighting in neon gold and hot pink, gentle glow. One single object, centered and fully visible, filling about 70% of a square frame with empty margin all around. Pure solid black background. No text, no letters, no logo, no watermark, no border, no floor, no person, not photorealistic, not cinematic. Square 1:1.
